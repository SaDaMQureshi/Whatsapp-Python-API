WHATSAPP MESSAGE API - SETUP GUIDE
===================================

PREREQUISITES:
- Python 3.15.1 (or higher)
- Chrome browser installed (default path: C:\Program Files\Google\Chrome\Application\chrome.exe)

INSTALLATION STEPS:
1. Open PowerShell/CMD in the project directory: "E:\My Data\Project\Whatsapp API"
2. Install dependencies:
   pip install -r requirements.txt

RUNNING THE SERVER:
Option 1: Using Python module (recommended)
   python -m uvicorn main:app --host 0.0.0.0 --port 8000

Option 2: Using uvicorn directly (if Scripts folder is in PATH)
   uvicorn main:app --host 0.0.0.0 --port 8000

The server will start on: http://0.0.0.0:8000



STOPPING THE SERVER:
Press CTRL+C in the terminal where the server is running

SET CHROME PATH (if different from default):
Set environment variable CHROME_PATH before running:
$env:CHROME_PATH = "C:\path\to\chrome.exe"
Or permanently via System Properties > Environment Variables

API ENDPOINTS:
POST /send - Send WhatsApp message
GET /docs - Interactive API documentation (Swagger UI)
GET /openapi.json - OpenAPI schema

FILES:
- main.py - FastAPI application
- requirements.txt - Python dependencies
